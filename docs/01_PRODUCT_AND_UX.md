# 01. 제품과 사용자 경험

## 1. 제품 정의

Browser Pet은 사용자가 웹서핑하는 동안 페이지 위에서 작은 반려동물과 함께하는 Chrome 확장 프로그램이다. 게임창을 계속 열어 둘 필요가 없다. 사용자는 필요할 때 쓰다듬고 위치를 옮기며, 방해가 되면 즉시 숨길 수 있다.

**첫 성공 기준:** 사용자가 여러 사이트를 오가며 30분 동안 켜 두어도 클릭과 입력이 불편하지 않고, 캐릭터의 행동이 자연스럽게 느껴진다. 이는 사용자 검증 목표이며 실제 결과가 아니다.

가장 중요한 순서는 페이지 안전성, 낮은 자원 사용, 안정적인 저장, 캐릭터 매력이다. 기능 수보다 이 네 가지를 우선한다.

## 2. MVP와 후속 범위

### MVP에 포함

| ID | 요구사항 | 도입 단계 |
| --- | --- | --- |
| BP-01 | 허용된 HTTP/HTTPS 최상위 페이지에 펫 한 마리를 표시한다 | P1 |
| BP-02 | Shadow DOM으로 UI를 분리하고 페이지 레이아웃을 변경하지 않는다 | P1 |
| BP-03 | 화면 안을 여러 방향으로 걷고 멈춤, 앉기, 잠자기를 전환한다 | P2 |
| BP-04 | 클릭 반응, 드래그로 위치 고정, 산책 다시 시작을 제공한다 | P3 |
| BP-05 | 팝업과 웹페이지의 작은 펫 메뉴를 제공한다 | P1/P3 |
| BP-06 | 여러 탭에서 이름, 설정, 고정 위치와 행동을 공유한다 | P1 기초, P4 완성 |
| BP-07 | 팝업 버튼 하나로 지원되는 웹페이지의 펫을 켜고 끈다 | P1/P3/P5 |
| BP-08 | 숨김 탭에서는 중단하고, 입력과 전체화면에서는 전체 스위치를 따른다 | P2/P5 |
| BP-09 | 크기와 이동 속도, 동작 줄이기를 설정한다 | P5 |
| BP-10 | 재시작, 확장 업데이트, 데이터 오류를 안전하게 처리한다 | P4/P5 |

### 별도 요청 후 구현

P7-B에서 팝업과 옵션의 **함께할 동물**에 고양이와 강아지 선택을 추가했다. 같은 펫의 모습만 바뀐다. 전체 표시가 꺼져 있어도 선택할 수 있고, 나중에 켜면 저장된 모습으로 나타난다. 레벨, 진화, 그 밖의 펫, 방 꾸미기, 수집, 집중 보상은 별도 범위다. P7에도 모든 기능을 한꺼번에 넣지 않는다.

로그인, 서버 동기화, 랭킹, 친구, 결제, AI 대화, 광고, 방문 사이트 분석, 브라우징 시간 측정은 현재 범위에 없다. 실제 사용자 수요가 확인되기 전에는 구조만 예상해 불필요하게 확장하지 않는다.

### P7-A 함께 돌보기

팝업에 포만감, 기분과 누적 경험치를 표시하고, 팝업과 펫 메뉴에서 먹이를 주거나 쓰다듬을 수 있다. 새 펫과 기존 펫 모두 육성 시작 시 포만감 70, 기분 70, 경험치 0이다. 먹이는 포만감 +20, 경험치 +5로 10분에 한 번, 쓰다듬기는 기분 +10, 경험치 +2로 1분에 한 번 보상한다. 제한은 같은 프로필 전체에 적용한다. 포만감과 기분은 0~100이며 누적 경험치는 별도의 정수다. 메뉴만 열거나 탭을 켜 둬도 경험치는 늘지 않는다.

### P8 놀이와 꾸미기

**공 던지기**는 펫 메뉴에서 시작한다. 강아지는 공을 물고 돌아오고, 고양이는 앞발로 쳐서 공을 남겨 둔 채 자신의 자리로 돌아간다. 경험치는 주지 않는다. 공은 장식이며 페이지의 링크와 입력을 가로채지 않는다. 차분한 성격은 공을 잠깐 보고, 활발한 성격은 바로 다가간다. 동작 줄이기가 켜져 있으면 쫓아가지 않고 공과 정지 자세만 잠시 표시한다.

옵션의 **스카프 옷장**에서 색을 미리 보고 착용하거나 벗는다. 착용 상태와 성격은 같은 프로필의 모든 탭에 저장된다. 먹이 보상이 생기면 팝업 미리보기와 보이는 페이지에서 밥그릇을 보여 준다. 반복 보상 대기 중인 클릭은 새 식사를 시작하지 않는다.

## 3. 동작 범위와 정직한 안내

| 상황 | MVP 동작 |
| --- | --- |
| 일반 HTTP/HTTPS 페이지, 사이트 접근 허용 | 페이지 위에 표시 |
| 팝업 닫기 | 페이지의 펫 유지 |
| 다른 탭으로 전환 | 같은 고양이의 현재 위치와 행동을 표시 |
| 숨겨진 탭 | 애니메이션과 행동 타이머 중지 |
| 여러 창에서 페이지가 동시에 보임 | 포커스된 일반 창의 활성 탭 한 곳에만 표시 |
| 로그인이나 결제용 별도 팝업 창, 또는 다른 앱이 앞에 있음 | 어느 창에도 표시하지 않고 일반 창으로 돌아오면 재개 |
| 브라우저 종료 | 화면 동작 중단, 이미 저장한 상태는 다음 실행에서 복원 |
| `chrome://`, 웹 스토어 등 보호 페이지 | 미지원 |
| 내장 PDF 뷰어, 새 탭 화면, 로컬 파일 | MVP 지원 대상 아님 |
| iframe 내부 | 별도 펫을 삽입하지 않음 |
| 주소창, 탭 표시줄, 바탕화면 | 미지원 |
| 시크릿 모드 | MVP에서 사용하지 않도록 설정 |

같은 프로필 안에서 창을 바꿔도 선택한 펫 한 마리의 상태를 이어간다. 브라우저 프로필이 다르면 데이터도 별개다. 같은 계정의 다른 컴퓨터와 자동 동기화되는 제품이 아니다. [S2, S3]

## 4. 첫 사용 흐름

설치 후 팝업에서 간단한 안내를 보여 준다. 첫 설정의 `enabled`는 false다. 팝업 제목 옆의 '펫 표시' 스위치를 켠다.

안내 문구 초안:

> 작은 친구가 지금 보는 화면을 산책해요. 사이트에 표시하기 위한 접근 권한이 필요해요. 이 버전은 페이지 내용이나 입력값을 수집하거나 서버로 보내지 않아요. 방해가 되면 언제든 숨길 수 있어요.

이 안내가 Chrome의 권한 승인 창을 대신하는 것은 아니다. 최초 설치 및 사이트 접근 권한은 Chrome이 별도로 관리한다. [S5]

시작 직후 기존 페이지에 나타나지 않으면 '일반 웹페이지를 새로고침해 주세요. Chrome 내부 화면에서는 표시되지 않아요.'를 안내한다. 설치한 확장 자체의 전체 접근을 끄면 일부 사이트에서는 동작하지 않을 수 있다.

## 5. 화면 구성

### 웹페이지의 펫

기본 크기는 64 CSS px, 초기 위치는 화면 오른쪽 아래에서 16px 안쪽이다. 대각선으로 화면 곳곳을 오가고 가장자리에서는 돌아선다. 드래그해서 놓으면 화면의 그 위치에 고정된다. 다시 끌어 옮기면 다른 탭에도 반영된다. 크기가 다른 창에서는 화면 내 상대 위치를 맞춘다. 스크롤하거나 전체 표시를 껐다 켜거나 Chrome을 재시작해도 고정 위치는 유지된다.

펫 본체만 포인터 이벤트를 받는다. 화면 전체를 덮는 투명 영역은 페이지 클릭과 스크롤을 통과시킨다. 이미지의 투명 픽셀까지 완벽하게 통과하는 픽셀 단위 히트 테스트는 MVP 범위가 아니므로, 실제 그림에 가깝게 상호작용 박스를 줄인다.

쓰다듬기 상태는 공유하되 현재 사용하는 일반 창에만 반응을 표시한다. 메뉴와 키보드 포커스는 조작 중인 페이지에만 적용한다. 더블클릭, 우클릭 가로채기, 전역 단축키는 추가하지 않는다.

### 펫 메뉴

'쓰다듬기'와 '모든 탭에서 숨기기'를 제공한다. 고정된 펫에서만 '산책 다시 시작'이 나타난다. 이 항목을 누르면 고정을 풀고 놓았던 자리에서 대각선으로 걷는다. 모든 탭에서 같은 상대 위치와 경로를 유지한다. 메뉴 마지막의 '설정 열기'는 팝업과 같은 옵션 화면을 연다. 펫이 숨겨진 동안에는 팝업에서 설정을 열 수 있다.

펫 메뉴에서 숨기면 팝업의 전체 표시 설정도 꺼진다. 팝업에서 전체 표시를 켜면 현재 사용하는 일반 창의 활성 탭에 다시 보인다.


### 팝업

폭 약 340px의 작은 화면으로 구성한다. 화면이 작으면 내부 세로 스크롤을 허용한다.

| 영역 | 내용 |
| --- | --- |
| 상단 | 프로젝트명, 펫 표시 스위치, 설정 톱니바퀴를 한 줄에 배치 |
| 펫 미리보기 | 현재 캐릭터, 이름, 함께할 동물 선택 |
| 주 동작 | 펫 표시 스위치로 모든 탭의 펫 켜기/끄기 |
| 이름 | 이름 수정 입력과 저장 버튼 |
| 바로가기 | 상단 톱니바퀴로 설정 열기 |
| 안내 | 보호 페이지 제한, 로컬 저장 안내, 오류 상태 |

팝업은 육성 게임의 메인 화면이 아니다. 현재 탭의 URL을 읽는 UI는 MVP에서 제공하지 않는다.

### 옵션 화면

크기 32/64/96px, 속도 느림/보통, 동작 줄이기 시스템 설정 따르기/항상 켜기, 로컬 데이터 초기화를 제공한다. 이름은 양끝 공백 제거 후 1~20 Unicode 코드포인트를 허용하며 줄바꿈과 제어문자는 거부한다.

전체 표시를 끄면 펫은 숨지만 이름과 설정은 유지된다. 초기화는 데이터를 삭제하고 새 기본 상태로 돌아가는 별도 기능이며, 확인 대화상자에서 무엇이 삭제되는지 명확히 설명한다.

## 6. 방해하지 않는 동작

전체 표시가 켜져 있으면 입력칸이나 iframe에 포커스가 있어도 펫이 유지된다. 입력 내용과 키 입력은 읽지 않는다.

페이지 전체화면에서도 펫 표시를 유지한다. 화면 크기가 달라지면 위치와 경계를 다시 계산한다.

동작 줄이기 설정이 유효하면 자동 산책, 반복 스프라이트와 장식 효과를 끄고 정적인 펫을 표시한다. 클릭 메뉴와 기본 조작은 그대로 가능하다. 소리는 기본적으로 없으며 MVP에서 추가하지 않는다.

## 7. 접근성과 시각 방향

캐릭터는 귀여운 픽셀아트, 관리 UI는 단순하고 읽기 쉬운 형태로 만든다. 큰 장식, 불필요한 애니메이션, 자주 뜨는 말풍선을 피한다. 컬러 팔레트와 최종 브랜드는 에셋 확정 후 조정한다.

펫과 메뉴는 키보드로 접근할 수 있고 Enter/Space로 열 수 있어야 한다. Escape는 펫 메뉴가 열려 있을 때만 닫는 데 사용한다. 페이지 전체 키 입력을 가로채지 않는다. 메뉴를 닫으면 가능한 경우 이전 펫 버튼으로 포커스를 돌린다. 접근 가능한 이름과 명확한 포커스 표시를 제공한다.

펫이 키보드 포커스를 받으면 자동 이동을 멈춰 포커스 대상을 따라다니게 하지 않는다. 이름 입력은 React 텍스트 렌더링을 사용하고 HTML로 해석하지 않는다.

## 8. MVP 승인 기준

동일 문서의 펫이 두 마리로 중복되지 않는다. 스크롤, 링크, 입력, 영상 컨트롤이 정상 동작한다. 설정 저장과 재시작 복원이 가능하고, 여러 탭의 수정이 서로 덮어써지지 않는다. 수동 검증과 에셋 확인이 남아 있으면 외부 사용자에게 배포하지 않는다.

출처 ID의 URL은 `05_TESTING_AND_RELEASE.md`에서 확인한다. 그 외 동작과 기본값은 본 프로젝트의 설계 결정이다.
