# Browser Pet 사용 안내

[제품 소개로 돌아가기](../README.md)

함께할 친구를 고르고, 돌보고, 꾸미는 방법을 모았어요.

## 처음 누룽 만나기

일반 웹사이트에서 확장 아이콘을 누르고 **누룽 만나기**를 선택한다. 누룽이 페이지에서 손을 흔든다. 새 탭이나 Chrome 설정 화면에서는 일반 웹사이트를 여는 방법이 나온다. 설치 전에 열어 놓은 웹사이트라면 한 번 새로고침한다. 그다음부터는 아이콘 옆 **펫 표시** 스위치로 친구들을 함께 켜고 끈다.

## 새 컴퓨터에서 이어서 돌보기

1. 기존 컴퓨터에서 **확장 아이콘 → 톱니바퀴 → 저장 데이터 → 백업 내보내기**를 누른다. 날짜가 붙은 JSON 파일이 내려받아진다.
2. 새 컴퓨터에 Browser Pet을 설치하고 같은 메뉴의 **백업 가져오기**에서 옮겨 온 파일을 선택한다. 백업한 날짜, 펫 이름, 이미지 펫 수와 알람 수를 확인한다.
3. **교체하고 가져오기**를 누르면 새 컴퓨터의 기록 전체가 백업 시점의 내용으로 바뀐다. 기존 기록도 보관하려면 교체 전에 그 기기에서 백업을 하나 내보낸다.

백업에는 직접 등록한 이미지와 GIF, 이름, 돌봄과 경험치, 옷, 방, 추억 카드, 위치, 타이머, 알람과 설정이 들어간다. 이미 다운로드한 네컷 사진은 파일을 따로 옮긴다. 새 기기에서도 알람을 받으려면 팝업의 알람 메뉴에서 **알람 예약 다시 허용**을 누른다. 시스템 알림은 해당 기기의 권한 설정을 따른다. 이후 각 컴퓨터의 변경 사항은 해당 기기에 저장된다.

## 다락방에서 친구 고르기

팝업의 가운데 방석에는 돌볼 친구가 앉고 양옆에는 먼저 꺼낸 친구가 최대 두 마리까지 앉는다. **나와 있는 펫**을 눌러 이름과 얼굴을 보고 친구를 고른다. 이미지 펫도 고를 수 있다. 선택하면 그 친구가 가운데로 오고 아래 돌봄 기록과 먹이 주기 대상이 함께 바뀐다. 팝업을 다시 열어도 선택이 유지된다.

가운데 친구를 숨기거나 삭제하면 남은 친구가 자리를 이어받는다. 전체 표시를 끄면 방이 비고, 다시 켜면 기억한 친구들이 돌아온다.

## 내 이미지로 펫 만들기

1. **톱니바퀴 → 내 친구 → 내 캐릭터**에서 **캐릭터 추가**를 누르거나 그림을 점선 카드 위에 놓는다. PNG, JPG, WebP, GIF를 받을 수 있다. 파일당 최대 5MB, GIF는 최대 120프레임이며 이미지 펫은 다섯 마리까지 등록할 수 있다.
2. 이름을 붙이고 **걷기, 깡충거리기, 꼬물꼬물 기기, 둥실거리기, 빙글 날기** 중 하나를 누른다. 내 그림이 바로 옆에서 선택한 동작을 보여 준다. 옆을 보는 그림은 **그림이 보는 방향**을 지정하면 산책할 때 진행 방향으로 돌아선다.
3. 새 그림은 **단색 배경 자동 제거**만 켠 2D 모습으로 시작한다. 이 옵션은 그림 가장자리와 이어진 단색 배경을 지운다. 무늬가 많은 배경에는 투명 PNG를 사용할 수 있다. 윤곽에 두께와 명암을 더하고 싶으면 **입체 스티커**를 켠다. 미리보기에서 모습을 고른 뒤 **내 펫으로 등록**을 누른다.

등록한 GIF는 웹페이지와 다락방에서 반복 재생된다. 동작 줄이기를 켜면 첫 그림을 표시한다. 그림은 표시 크기에 맞게 줄여 이 Chrome 프로필에만 저장한다. 원본 파일은 그대로 남는다.

얼굴 카드를 눌러 각 친구를 꺼내거나 숨긴다. 연필 버튼에서는 이름, 크기와 움직임을 바꿀 수 있다. 이미지 펫은 연필을 누른 뒤 **모습 적용**으로 저장한다. 삭제하려면 같은 창의 **이 이미지 펫 삭제 → 삭제하기**를 누른다. 웹페이지에서의 위치와 돌봄 기록은 친구마다 따로 기억해 다른 탭에서도 이어진다. 옷장과 장난감 놀이는 기본 친구 전용이다.

## 기본 조작

- **지원 언어:** 한국어, 일본어, 영어, 스페인어. Chrome의 표시 언어에 따라 팝업과 설정, 페이지 위 펫 메뉴, 말풍선, 타이머가 바뀐다. 그 외 언어는 영어를 사용하며, 저장된 펫 이름은 바꾸지 않는다.
- **함께할 동물:** 꼬깃은 종이부채 꼬리 뒤에 숨는 날다람쥐, 누룽은 긴 귀를 베고 뒷발을 드는 강아지, 퐁당은 장화 한 짝으로 걷는 오리다. 팝업의 **친구 선택과 이름** 또는 **톱니바퀴 → 내 친구**에서 함께 표시할 친구를 켠다. 기본 세 친구와 등록한 이미지 펫을 함께 표시할 수 있다. 별명, 돌봄, 옷, 크기, 움직임과 위치는 각자 기억하고 각 친구의 상태를 탭 사이에서 이어 간다. 알람과 타이머는 함께 쓴다.
- **친구별 설정:** **톱니바퀴 → 내 친구**에서 기본 친구 카드의 연필을 누르면 카드 아래에 해당 친구의 이름, 크기, 움직임이 나온다. 이름은 입력 후 저장하고 크기와 움직임은 선택하면 적용된다. 얼굴 카드로 웹페이지에 나올 친구를 고른다.
- **알림 담당:** 표시 중인 친구 중 편집 대상으로 고른 친구가 알람과 타이머를 보여 준다. 그 친구가 꺼져 있으면 다른 표시 중인 친구 한 마리가 맡는다. 여러 마리 위에 같은 알림이 반복되지 않는다.
- **이전 프로필:** 기존에 선택했던 동물의 별명과 돌봄은 후임 친구에게 이어진다. 기존 기본 이름은 새 캐릭터 이름으로 바뀐다. 같은 후임에 해당하는 기록이 여럿이면 현재 선택을 우선하고, 나머지 원본 기록은 기기 안에 보관한다. [시그니처 원화와 이관 규칙](SIGNATURE_FRIENDS.md)
- **포즈 수첩:** **톱니바퀴 → 포즈 수첩**에서 고른 동물의 낮잠, 식사, 하이파이브, 태엽 쥐와 동물별 버릇 등 열세 가지 입체 포즈를 96px와 32px로 볼 수 있다. 수첩의 선택은 실제 펫의 행동이나 돌봄 기록에 영향을 주지 않는다.
- **알람:** 일반 웹페이지에서 **펫 → 알람 관리** 또는 확장 아이콘의 **알람**을 연다. 알람에 이름을 붙이고 **한 번 / 매일 / 평일 / 매주 / 매월**과 시각을 고른다. 매주는 요일, 매월은 날짜(1~31일)를 정한다. 선택한 날이 없는 달에만 말일에 울린다. 예를 들어 매월 31일은 2월 말일에 울린 뒤 3월 31일로 돌아간다. 여러 알람(최대 32개)을 각각 켜거나 끌 수 있다.
- **알림 받기:** 기기의 현지 시각을 쓰며 동물이나 탭을 바꿔도 일정을 함께 쓴다. 펫 위에 먼저 울린 알람부터 이름, 예약 시각, 미확인 개수를 표시한다. 말풍선은 **확인**을 누를 때까지 남고, 하나 확인하면 다음 알람이 나온다. 탭 전환, 새로고침, Chrome 재시작 뒤에도 미확인 상태가 이어진다. 팝업의 **알람 → 미확인 알람**에서는 원하는 항목부터 확인할 수 있다. 알람 확인은 반복 예약을 끄지 않는다. 펫이 숨겨져도 받으려면 **알림 방식 → 시스템 알림도 받기**를 켠다. 팝업을 닫아도 예약은 유지된다. Chrome 종료·절전 중에는 정시에 알리지 못하며 다시 열면 지난 회차가 기록된다. 반복 일정은 가장 최근에 지난 회차만 기록한다.
- **공부 타이머:** 팝업의 창가 아래 **공부 타이머**에서 집중(기본 25분) 또는 문제 풀이(기본 50분)를 선택하고 1~180분으로 맞춘다. 문제 풀이는 현재 보고 있는 시험지나 문제집의 시간을 재는 모드다. 팝업을 닫아도 진행하며 일시정지, 이어서, 종료가 가능하다. 일반 웹페이지에서는 펫 바로 위에 **집중 24:59** 또는 **문제 풀이 49:59**처럼 모드와 남은 시간이 표시된다. 일시정지하면 숫자가 멈추고 일시정지 표시가 붙는다. 화면 위에 공간이 없으면 펫 아래에 표시한다. 시간이 끝나면 시간표시 대신 기존 완료 말풍선이 잠시 뜬다. 브라우저가 닫혀 있거나 펫이 숨겨져 있으면 다음에 팝업에서 완료를 확인한다.
- **펫 말풍선:** 일반 웹페이지에서 펫이 가끔 “안녕?” 하고 인사하거나 기기의 현지 시각을 알려 준다. 한마디는 약 5초간 보인다. 글을 쓰거나 전체화면을 보는 동안에는 조용하다. 펫을 그대로 두고 말풍선만 끄려면 **톱니바퀴 → 모습과 행동 → 말풍선 → 끄기**를 선택한다.
- **공놀이:** 또또 메뉴의 **공 던지기**로 시작한다. 누룽은 공을 물어 오고 꼬깃은 앞발로 쳐서 굴린다. 놀이 후에는 원래 고정 자리나 산책으로 돌아간다.
- **장난감 상자:** 일반 웹페이지에서 펫을 누르면 **장난감 상자 → 태엽 쥐**가 보인다. 이 동물이 7 XP를 모으면 열린다. 이미 얻은 XP가 포함되고 놀이로 XP를 소모하지 않는다. 꼬깃은 달리는 쥐를 앞발로 덮치고 누룽은 코로 밀어 준다. 쥐가 달릴 때는 등에 달린 황동 열쇠와 바퀴가 함께 돈다. 처음부터 쓸 수 있는 공놀이에서는 줄무늬 공이 굴러간다.
- **하이파이브:** 일반 웹페이지에서 펫을 눌러 **하이파이브**를 고른 뒤, 머리 위에 **하이파이브 할까?** 말풍선이 뜨면 펫이나 말풍선을 누른다. 같은 자리에 **짝!**이 잠깐 뜬다. 화면 위쪽에 공간이 없으면 펫 아래에 표시한다. 입체 모형이 발바닥이나 날개 끝을 앞으로 내밀었다가 거둔다. 키보드로는 펫에 포커스를 두고 Enter 또는 Space를 누른다. 15초가 지나면 원래 행동으로 돌아가며 고정 위치는 바뀌지 않는다.
- **웹페이지의 입체 펫:** 일반 사이트에서 세 친구 모두 입체 모형으로 걷는다. 펫을 누르고 **360° 보기** 슬라이더를 움직이거나 **뒷모습**을 눌러 제자리에서 볼 수 있다. 산책 중에 메뉴를 열면 그 자리에서 기다린다. 메뉴를 닫으면 기다린 시간을 건너뛰고 같은 위치와 방향에서 이어 걷는다. 고정한 펫은 그대로 남는다. 펫 자체를 끌면 이전처럼 위치가 고정된다.
- **팝업과 설정의 입체 펫:** 도구 모음의 누룽 아이콘을 누르면 다락방 방석에 선택한 펫이 입체로 나온다. 설정의 옷장에서는 옷을 골라 앞모습, 옆모습, 뒷모습을 보고 적용할 수 있다. 추억 앨범과 액자는 기록 당시의 차림을 보여 준다.
- **팝업의 360° 보기:** 확장 아이콘을 누르고 다락방 그림 왼쪽 위의 **360° 보기**를 선택한다. 현재 동물과 차림을 좌우로 끌거나 앞모습, 옆모습, 뒷모습을 누른다. **방으로**를 누르면 돌아온다.
- **동물마다 다른 버릇:** 웹페이지에서 산책하다 쉬거나 고정된 자리에 머물면 가끔 꼬깃은 종이부채 꼬리 뒤에 숨고, 누룽은 긴 귀를 베고 졸고, 퐁당은 장화 한 짝으로 뒤뚱거린다. 세 친구의 버릇은 **설정 → 포즈 수첩 → 포즈 고르기**의 마지막 항목에서 바로 볼 수 있다. 동작 줄이기에서는 수첩에 대표 자세만 표시한다.
- **다락방 종이상자:** **팝업 → 방 꾸미기 → 방에 놓을 장난감 → 종이상자**를 누르면 놓이고 다시 누르면 치운다. 꼬깃은 꼬리를 내밀고, 누룽은 귀를 걸치고, 퐁당은 양 날개를 펼친다. 놓아 둔 상태에서 **상자로 다시 놀기**를 눌러 그 동물의 반응을 다시 볼 수 있다. 상자 선택은 동물마다 기억한다.
- **햇살 다락방:** 확장 아이콘에서 **방 꾸미기**를 누르면 잎사귀 자수, 살구 체크, 남빛 별밤 방석 중 하나를 고를 수 있다. 같은 곳에서 들꽃 그림이나 이 동물의 추억 카드를 골라 벽에 건다. 앨범의 **방에 걸기**와 **벽에서 내리기**도 같은 액자에 반영된다. XP가 필요하지 않고 동물별로 선택을 기억한다. 방석과 액자는 팝업 안의 장식이다.
- **또또네컷:** 확장 아이콘을 눌러 **또또네컷**에서 배경색을 고르고 **네컷 찍기**를 누른다. 선택한 동물이 지금 차림으로 찍은 정면, 옆모습, 하이파이브, 낮잠에 이름과 촬영일을 넣어 한 장의 PNG로 저장한다. 사진을 보관하려면 팝업을 닫기 전에 **PNG 저장**을 누른다.
- **추억 앨범:** 확장 아이콘을 누르고 **추억 앨범**을 펼친다. 선택한 동물의 첫 하이파이브, 첫 공놀이, 태엽 쥐 놀이, 산타 코트 적용, 25분 이상 집중 타이머 완료를 각 한 장씩 모은다. 집중 카드는 시작할 때 함께한 동물과 차림으로 남고, 일찍 종료한 세션은 세지 않는다. 과거의 사건은 소급해 만들지 않는다. 카드는 화면 캡처 없이 펫 그림으로 만든다.
- **성격과 옷장:** **톱니바퀴 → 모습과 행동 → 성격**에서 공을 보고 기다릴지 바로 쫓을지 고른다. **톱니바퀴 → 옷장**에서 데님 멜빵바지, 산타 코트, 솔잎 요정복, 순록 조끼를 미리 입혀 보고 스카프를 따로 고른다. **차림 적용**을 누르면 팝업과 같은 프로필의 웹페이지에 반영된다. 옷이나 스카프만 따로 벗길 수도 있다.
- **돌보기:** 펫 메뉴나 팝업에서 **먹이 주기**와 **쓰다듬기**를 누른다. 포만감, 기분, 누적 경험치는 팝업에서 확인한다. 먹이는 10분에 한 번 포만감 +20, 경험치 +5를 주고, 쓰다듬기는 1분에 한 번 기분 +10, 경험치 +2를 준다. 먹이가 실제로 지급되면 잠깐 밥그릇이 나타난다. 메뉴를 열기만 하면 하트만 뜬다. 같은 동물의 대기시간은 팝업과 모든 탭이 공유한다. 예를 들어 꼬깃에게 방금 먹였어도 누룽에게는 바로 먹이를 줄 수 있다.
- **켰는데 안 보일 때:** Browser Pet 팝업에서 **펫 표시**를 켠 뒤 프로필 아래 안내로 창 상태 또는 페이지 연결 여부를 확인할 수 있다. 이 안내는 전체 표시 스위치와 별개다.
- **여러 창과 팝업:** 또또는 현재 사용하는 일반 Chrome 창의 선택된 탭에만 나타난다. 로그인이나 결제처럼 별도로 열린 팝업에서는 숨고, 일반 창으로 돌아가면 같은 위치와 행동을 이어간다.
- **전체 표시:** 팝업 제목 옆 **펫 표시** 스위치로 켜거나 끈다. 끄면 모든 친구를 숨기며, 다시 켜면 함께 표시하던 친구들이 돌아온다. 마지막 친구를 개별로 끄면 전체 표시도 꺼지고, 이때 전체 스위치를 켜면 편집 중인 친구 한 마리를 표시한다. 스위치가 현재 일반 탭에 직접 표시 명령을 보내며 같은 클릭의 설정은 백그라운드에서 저장한다. 입력 중이거나 전체화면이어도 켜짐을 유지하고, 이전 버전에서 숨겼던 사이트에도 같은 버튼이 적용된다.
- **위치:** 펫을 잠깐 누르고 있거나 끌면 몸을 매단 채 발이나 날개를 움직인다. 좌우로 빠르게 옮기면 잡은 곳을 중심으로 몸이 살짝 뒤따라 흔들린다. 끌어 놓으면 흔들림이 멈추고 그 자리에 고정된다. 창 크기가 다른 탭에서는 같은 비율의 위치에 보인다. 새 문서를 열거나 Chrome을 다시 열어도 고정한 자리를 기억한다. 펫 메뉴의 **산책 다시 시작**을 누르면 놓은 자리에서 출발해 화면 곳곳을 대각선으로 오간다. 다른 탭에서도 가로와 세로 위치 비율을 함께 이어간다.
- **쓰다듬기:** 펫을 클릭하면 하트가 뜨고, 반응은 같은 프로필에 공유된다. 다른 창으로 옮기면 그 시점의 모습을 이어서 본다. 작은 메뉴는 클릭한 페이지에만 열린다. 키보드로는 Tab으로 펫을 선택하고 Enter나 Space로 메뉴를 열며 Esc로 닫는다.
- **이름:** 팝업의 **친구 선택과 이름**을 펼치고 이름 입력칸에 1~20자로 입력하고 **이름 저장**을 누른다. 예를 들어 꼬깃에게 ‘또또’, 누룽에게 ‘보리’라고 지으면 동물을 바꿀 때 팝업, 설정, 열린 탭의 메뉴에 그 동물의 이름이 표시된다. 예전 공용 이름은 업데이트 시 선택된 동물이 이어받는다. **설정 열기**에서는 데이터를 확인 후 초기화할 수 있다.

웹페이지에서 펫을 누르면 이름 아래에 **쓰다듬기**, **먹이 주기**, **공 던지기**가 나란히 보인다. 메뉴 맨 아래 오른쪽 **톱니바퀴(설정 열기)**로 설정에 들어간다. 펫이 숨은 상태에서는 Browser Pet 팝업 오른쪽 위 **톱니바퀴(설정 열기)**를 누르세요. **모습과 행동**에서 크기(32/64/96px), 산책 속도, 동작 줄이기를 바꿀 수 있다.
