# 다락방의 세 친구

출시 라인업은 꼬깃, 누룽, 퐁당이다. 선택 카드에는 이 프로젝트에서 만든 [승인 원화](../assets/signatures/attic-friends.webp)를 사용한다. 웹페이지, 다락방, 옷장과 포즈 수첩은 같은 친구의 회전 가능한 모형을 사용한다. 원화 한 장을 돌리는 방식이 아니라 몸, 귀, 발, 꼬리와 날개를 따로 그린다. 외부 캐릭터 그림이나 모델을 구매하거나 내려받지 않았다.

| 친구 | 작은 크기에서도 보이는 특징 | 하이파이브 |
| --- | --- | --- |
| 꼬깃 (Kkogit) | 접은 쪽지를 안고 종이부채처럼 접힌 꼬리를 세우는 밤색 날다람쥐 | 쪽지를 품고 앞발 하나를 내민다. |
| 누룽 (Nurung) | 바닥에 긴 귀가 닿는 노릇노릇한 졸음 강아지 | 누운 채 뒷발을 든다. |
| 퐁당 (Pongdang) | 커다란 장화 한 짝을 신은 청록빛 아기 오리 | 양 날개를 활짝 펼친다. |

새 설치는 누룽으로 시작한다. 현재 친구의 별명을 지어도 나머지 두 친구의 이름은 변하지 않는다. 경험치와 돌봄도 개별 기록이다. 위치, 공부 타이머와 알람은 전처럼 공유한다.

## 기존 사용자

이전 버전에서 쓰던 동물을 다음 친구에게 연결한다.

| 새 친구 | 이전 친구 |
| --- | --- |
| 꼬깃 | 고양이, 토끼, 햄스터, 레서판다, 고슴도치 |
| 누룽 | 강아지, 여우, 수달 |
| 퐁당 | 오리, 펭귄 |

각 그룹에서는 현재 선택한 친구가 최우선이다. 다른 그룹은 고양이, 강아지, 오리 기록을 각각 우선하고, 그 기록이 없으면 그룹에 저장된 첫 기록을 쓴다. 별명, 포만감, 기분, 경험치와 먹이 대기 시간이 이어진다. 예전 기본 이름과 정확히 일치하는 이름은 새 친구의 기본 이름으로 표시한다.

같은 후임으로 모이는 기록의 경험치를 더하거나 다른 친구의 방으로 합치지 않는다. 후임에게 이어 준 방과 추억 카드에는 사본을 만들고 이전 이름과 돌봄 원본도 로컬에 보관한다. 이 원본은 선택 목록에는 표시하지 않는다. 이전에 PNG로 내보낸 사진은 바뀌지 않는다.
