# Browser Pet 0.1.0 | 첫 제출 준비표

이 폴더는 개발자 대시보드에 사용할 자료다. **확장 업로드 파일은 npm run zip으로 생성한 ZIP 하나**다. 이 문서, 개인정보 페이지 또는 이미지를 담은 디렉터리를 확장으로 업로드하지 않는다. 현재 계정 생성, 결제, 업로드, 공개 URL 배포 및 제출은 수행하지 않았다.

## 준비한 자료

- [스토어 문안](STORE_LISTING.md): 한국어, 일본어, 영어, 스페인어 설명과 심사자 재현 순서. 제품 이름과 요약은 ZIP에 있는 manifest 및 각 언어 메시지와 맞춘다.
- [개인정보 페이지](privacy.html): 게시 가능한 한국어·영어 정적 HTML. 개발자가 관리하는 누구나 열 수 있는 HTTPS URL에 올린 뒤 실제 주소를 입력한다. 로컬 파일 경로나 없는 URL을 제출하지 않는다.
- [아이콘](media/store-icon-128.png), [작은 홍보 타일](media/promo-440x280.png)
- 한국어 스크린샷 제출 순서
  1. [내 그림이 웹페이지를 산책해요](media/01-image-pet-ko.png). 촬영용으로 직접 만든 새싹콩 그림과 등록 후 웹페이지를 걷는 2D 펫.
  2. [다락방에 모인 세 친구](media/02-attic-ko.png). 꼬깃, 누룽, 퐁당을 함께 표시한 실제 팝업.
  3. [머리 위의 집중 타이머](media/03-focus-ko.png). 집중 시간을 시작한 뒤 실제 웹페이지에 표시된 카운트다운.
- 사진 속 웹페이지는 촬영용 로컬 예시다. 문안은 네 언어로 제공하고 이번 스크린샷의 UI 언어는 한국어다.

## Privacy Practices 입력 초안

| 입력 항목 | 실제 용도 |
| --- | --- |
| 단일 목적 | 사용자가 고른 반려동물을 일반 웹페이지에서 돌보고 상호작용하는 기능. 집중 시간과 직접 등록한 일정은 같은 반려동물이 알려 준다. |
| storage (필수) | 같은 로컬 프로필의 탭에서 펫 선택, 위치, 돌봄, 설정, 사용자가 만든 일정과 최근 알람을 유지한다. |
| 사이트 접근 | 최상위 HTTP 및 HTTPS 페이지에만 번들된 콘텐츠 스크립트를 넣어 펫을 표시한다. 사이트 본문, 입력 내용이나 방문 기록을 수집하거나 전송하지 않는다. 선언형 matches이며 별도의 tabs, history, scripting 권한은 없다. |
| alarms (선택) | 사용자가 시간을 지정한 경우에만 워커를 깨운다. 첫 일정 저장 시 요청하고 쓸 일정이 없으면 예약을 해제한다. |
| notifications (선택) | 사용자가 시스템 알림을 켠 경우 등록한 알람 이름을 OS 알림에 표시한다. |
| 원격 코드 | 아니오. 실행 JS와 렌더러는 패키지 안에 있으며, 외부 모델·분석 스크립트·CDN을 호출하지 않는다. |
| 사용자 데이터 | 자유 입력한 펫 이름과 알람 이름, 시간·반복·최근 기록, 이전 버전에서만 지정했던 월급일, 설정과 이전 숨김 hostname이 로컬에 남을 수 있다. 입력한 복약 알람도 그대로 표시되지만 건강 기록이나 메일을 조회하지 않는다. 등록한 이미지와 GIF의 표시용 픽셀은 확장 저장소에 보관한다. 내보낸 JSON 백업과 네컷 PNG는 사용자가 직접 저장하는 파일이다. |

로컬 저장도 공개 대상이다. 실제 대시보드의 수집·사용 정의에 맞춰 항목을 검토하고, ‘아무 데이터도 다루지 않음’으로 일괄 기입하지 않는다. 웹사이트 내용, 계좌 정보나 메일을 다룬다고 기재하지도 않는다. 약속할 수 있는 데이터 사용 인증만 개발자가 직접 확인한다.

## 공개 전 순서

1. **일반 Chrome 최종 사용**. 정식 Chrome 157의 별도 프로필에서 새 설치의 실제 툴바, 네 언어, 이전 로컬 ZIP의 꺼짐 상태 보존을 확인했다. 30분 연속 실사용, 물리 모니터 사이의 창 전환, 장기 CPU 및 메모리와 워커 유휴 상태는 수동 확인이 남았다.
2. **기기에서 확인할 항목**
   - 두 모니터에 일반 Chrome 창을 하나씩 놓고 창을 번갈아 클릭한다. 친구가 키보드 입력을 받는 창에만 나타나는지 확인한다. 평소 사이트를 30분간 오가며 Chrome 작업 관리자의 CPU와 메모리를 확인한다.
   - 1분 뒤 울릴 테스트 알람을 만들고 시스템 알림을 켠 뒤 팝업을 닫는다. 알림 허용, 거부, 방해 금지 상태에서 각각 확인한다. 기기를 잠자기 상태에 두어 예약 시각을 넘긴 다음, 복귀 시 펫의 알림을 확인하고 한 번만 지워지는지 본다.
3. **게시자 자료:** 소유자가 세 친구의 최종 모형과 아이콘을 승인하고, 공개할 개발자 이름과 개인정보처리방침 URL, 배포 지역과 공개 범위를 확정한다. 스토어 연락처는 sangdonidoni@gmail.com로 정했다. 개발자 대시보드에서 이 주소의 이메일 인증을 완료한다. 필요한 개발자 등록 및 2단계 인증은 소유자 계정에서 처리한다.
4. **별도 제출 승인 후:** 해당 버전 ZIP 업로드 → 스토어 문안 및 이미지 → 개인정보·권한 설명 → 배포 범위 → 대시보드 미리보기와 경고 확인 → 심사 제출. 같은 버전 ZIP을 이미 업로드했다면 버전 증가가 필요할 수 있다. 심사 통과를 가정하지 않는다.
